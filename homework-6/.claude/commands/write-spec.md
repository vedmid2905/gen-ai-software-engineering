# Write Specification

Create a complete project specification following the structure in specification.md.

Steps:
1. Review the project context and any sample input data.
2. Draft a specification with the required sections: High-Level Objective, Mid-Level Objectives, Implementation Notes, Context, and Low-Level Tasks.
3. Write the result to specification.md.
4. Update agents.md with the project-specific agent roles and workflow.
5. Keep the specification concrete, testable, and aligned with the repository context.
