# How to Run

## 1. Prerequisites

- **Python 3.10+** (standard library only — no `pip install` needed for the app or its tests)
- **Claude Code CLI** (`claude`) on your `PATH`, authenticated, if you want to run
  `run-pipeline.sh` itself against a *new* bug (the artifacts for bug `001` are
  already committed under `context/bugs/001/` from a completed run)

## 2. Run the sample application (TaskFlow)

```bash
cd homework-4
python run.py add "Milk run" --priority 1
python run.py add "Low prio" --priority 2
python run.py add "High prio" --priority 10
python run.py list --search Milk
python run.py list --sort priority
python run.py stats
python run.py export out.txt --grep milk
```

## 3. Run the test suite

```bash
python -m unittest discover -s tests -v
```

Expect **20/20 tests passing**: 11 pre-existing baseline tests plus 9 tests
generated by the Unit Test Generator agent for bug 001
(`tests/test_bug_001_fixes.py`).

## 4. Run the full 4-agent pipeline (single command)

```bash
./run-pipeline.sh 001
```

This runs, in order, against `context/bugs/001/bug-context.md`:
**Bug Researcher → Bug Research Verifier → Bug Planner → Bug Fixer → Security
Verifier → Unit Test Generator** — each stage is its own `claude -p` invocation
using the matching `agents/*.agent.md` file as its system prompt (so the model and
required skill load automatically per agent) and stops the whole run if any stage
fails to produce its expected output file.

To run the pipeline against a **new** seeded bug: create
`context/bugs/00N/bug-context.md` describing it, then run
`./run-pipeline.sh 00N`.

> The artifacts already committed under `context/bugs/001/` (research, verified
> research, plan, fix summary, security report, test report) and the fixes already
> applied to `src/taskflow/` are the recorded output of one full run of this exact
> script/process — re-running it is optional and will re-derive the same
> conclusions from the current (already-fixed) source.

## 5. Inspect the pipeline outputs

```
context/bugs/001/
├── bug-context.md               # the 2 seeded bugs + 1 seeded vulnerability
├── research/codebase-research.md
├── research/verified-research.md   # Research Quality: Level 4 — VERIFIED
├── implementation-plan.md
├── fix-summary.md                  # 3 changes applied, tests run after each
├── security-report.md              # 1 resolved finding, 1 HIGH, 1 INFO
└── test-report.md                  # 9 new tests, 20/20 total passing
```

## 6. Demo checklist

1. `python -m unittest discover -s tests -v` → 20/20 passing.
2. `python run.py list --search Milk` after adding `"Milk run"` → task is now
   returned (was silently dropped before the fix).
3. `python run.py list --sort priority` with priorities `2` and `10` added → `10`
   now sorts first (was reversed before the fix).
4. `python run.py export out.txt --grep "x & echo pwned> pwned.txt & rem"` → no
   `pwned.txt` is created (the shell metacharacters are now inert, non-matching
   text — previously this created an arbitrary file).
5. Read `context/bugs/001/security-report.md` and `test-report.md` for the full
   review and test evidence.
